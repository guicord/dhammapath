# Story 02: Navigate from overview to concept detail

## User story
As a learner, I want to click a concept in the map so that I can read its explanation and learn more.

## Acceptance criteria
- Each concept presented in the map is clickable.
- Clicking a concept opens a dedicated concept detail view.
- The detail view includes the concept name, summary, and explanation.
- The user can return to the overview without losing context.

## Notes
- This is the gateway from overview to learning depth.
- Navigation should feel direct and low-friction.
