# Story 05: Read the source text

## User story
As a learner, I want links to canonical Theravada references so that I can study the original teachings directly.

## Acceptance criteria
- Each concept page includes a “Read the source” section.
- The section contains direct links to trusted Theravada source material.
- Source links are clearly attributed.
- The app distinguishes between summary explanation and primary source reference.
- New concepts can be linked to source material without redesigning the app.

## Notes
- Source links are critical to trust and depth.
- The product should help users move from summary to primary text.
