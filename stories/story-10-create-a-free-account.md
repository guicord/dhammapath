# Story 10: Create a free account

## User story
As a new user, I want to create a free account so that I can start learning without paying upfront.

## Acceptance criteria
- A user can create an account with a simple sign-up flow.
- The app allows a user to access core learning content immediately after sign-up.
- The account stores the user’s progress and quiz results.
- The user can log in again and resume learning.

## Notes
- Free access is important to reduce friction and increase adoption.
- The app should prioritize a simple onboarding experience.
